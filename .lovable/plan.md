
# تحليل الأسعار كشيت Excel

## الهدف
تحويل صفحة `/price-analysis` من واجهة بطاقات إلى **شيت Excel-style** كامل لكل بند BOQ، مع استيراد وتصدير ملفات Excel.

## الشكل العام

شريط علوي:
- اختيار البند من قائمة منسدلة (بدل القائمة الجانبية) — يوفّر مساحة للشيت.
- أزرار: **إضافة صف**، **استيراد Excel**، **تصدير Excel**، **حفظ**.
- معلومات البند: رقم/وصف/كمية/سعر البيع المحسوب.

الشيت نفسه (مكوّن واحد قابل لإعادة الاستخدام مبني على نفس أساس `boq-grid.tsx`):

```text
┌─────┬─────────────────────────┬──────┬──────┬────────────┬──────────┬──────────┐
│ نوع │ الوصف                    │ الوحدة │ الكمية │ سعر الوحدة │ الإجمالي │ إجراءات │
├─────┼─────────────────────────┼──────┼──────┼────────────┼──────────┼──────────┤
│ مواد │ — صف عنوان مجموعة —      │      │      │            │ المجموع   │          │
│ مواد │ خرسانة جاهزة 350         │ م³   │ 1.05 │ 350.00     │ 367.50    │  🗑️      │
│ مواد │ ...                      │      │      │            │           │          │
│ عمالة│ — صف عنوان مجموعة —      │      │      │            │ المجموع   │          │
│ ...                                                                                  │
└─────┴─────────────────────────┴──────┴──────┴────────────┴──────────┴──────────┘
شريط الهوامش (Markup): غير مباشرة % | مصاريف عامة % | مخاطر % | ربح %  → سعر البيع
```

## التفاصيل

### 1) ميزات الشيت (مطابقة لجدول الكميات)
- أعمدة قابلة لتغيير الحجم بالسحب، محفوظة في `localStorage` لكل بند BOQ.
- صفوف قابلة لتغيير الارتفاع لكل صف.
- **تحرير مباشر** بالنقر المزدوج على: الوصف، الوحدة، الكمية، سعر الوحدة.
- حساب فوري لعمود الإجمالي (`quantity × unit_price`).
- تنسيق الخلية (Bold/Italic/محاذاة/حجم خط) عبر Popover صغير — يُخزن في حقل JSON جديد `cell_styles` على `price_analysis_items`.
- صفوف عناوين للأقسام الأربعة (مواد/عمالة/معدات/مقاول باطن) مع مجموع فرعي.

### 2) إضافة صف
- زر **+ إضافة صف** يفتح قائمة منسدلة فيها أنواع الموارد الأربعة → عند الاختيار يضيف صفاً فارغاً قابلاً للتحرير.
- أو اختيار مورد موجود من قاعدة الموارد (autocomplete في خلية الوصف اختيارياً لاحقاً).

### 3) شريط الهوامش والملخص
يبقى في الأسفل ولكن مدمج بصرياً كصف-أدوات Excel-style:
- التكلفة المباشرة (محسوبة)
- 4 إدخالات نسبة مئوية للهوامش (تحرير فوري)
- سعر البيع للوحدة + الإجمالي للكمية بإطار بارز.

### 4) استيراد Excel
- زر **استيراد** يفتح Dialog مشابه لـ `import-excel-dialog.tsx`.
- يقرأ أعمدة: `النوع` (مواد/عمالة/معدات/مقاول باطن)، `الوصف`، `الوحدة`، `الكمية`، `سعر الوحدة`.
- صفوف الهوامش (إن وُجدت بصيغة `Indirect %`, `Overhead %`, `Risk %`, `Profit %`) تُحفظ في `price_analysis_markup`.
- يحل محل بنود التحليل الحالية للبند (بعد تأكيد) أو يُضيف إليها.

### 5) تصدير Excel
- زر **تصدير** يولّد `.xlsx` للبند الحالي بنفس بنية الاستيراد:
  - رأس بمعلومات البند (رقم، وصف، كمية، وحدة).
  - جدول البنود مقسّماً لأقسام النوع مع مجاميع فرعية.
  - صف الهوامش وسعر البيع النهائي.
- خيار إضافي: **تصدير كل بنود المشروع** (شيت لكل بند، أو شيت موحّد).

## التغييرات التقنية

### Migration
```sql
ALTER TABLE public.price_analysis_items
  ADD COLUMN IF NOT EXISTS cell_styles jsonb,
  ADD COLUMN IF NOT EXISTS sort_order int DEFAULT 0;
```

### ملفات جديدة
- `src/components/price-analysis/pa-grid.tsx` — الشيت القابل للتحرير.
- `src/components/price-analysis/import-pa-dialog.tsx` — استيراد Excel.
- `src/lib/pa-export.ts` — توليد ملف Excel للتصدير باستخدام `xlsx` (موجود بالفعل في المشروع لأن استيراد BOQ يستخدمه).

### ملفات معدّلة
- `src/routes/_authenticated/price-analysis.tsx` — استبدال `PriceAnalysisDetail` بـ `PaGrid`، وقائمة البنود بـ Select في الأعلى.

### اعتبارات
- لا تغييرات على RLS؛ الأعمدة الجديدة nullable.
- يستفيد المكوّن من نفس نمط `boq-grid.tsx` (تغيير حجم/تنسيق خلية) للحفاظ على تجربة موحّدة.
- التصدير يعتمد على `xlsx` فقط (لا حاجة لمكتبة جديدة).
