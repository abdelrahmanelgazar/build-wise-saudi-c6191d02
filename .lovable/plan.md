# خطة التعديلات على جدول الكميات (BOQ)

## 1) المحافظة على نفس شكل وترتيب ملف Excel عند الاستيراد

**المشكلة الحالية:** عند استيراد الملف، يتم إعادة بناء بنية هرمية تعتمد على ترقيم البنود (01، 01.01…) ويتم تجاهل ترتيب الصفوف الأصلي والأعمدة الإضافية. النتيجة: شكل مختلف عن الملف.

**الحل:**
- حفظ ترتيب الصفوف كما هو في Excel عبر `sort_order` تصاعدي حسب موضع الصف.
- حفظ **كل الأعمدة الأصلية** من الملف (حتى غير المعروفة) في حقل JSON جديد `raw_row` على جدول `boq_items` (migration).
- حفظ **رؤوس الأعمدة الأصلية** على مستوى المشروع في حقل JSON جديد `excel_headers` على جدول `projects`، حتى يعرضها الجدول بنفس الترتيب والأسماء.
- اكتشاف المجموعات يبقى تلقائياً، لكن لا يُعاد ترتيب الصفوف؛ تُحفظ كما هي.

## 2) جدول قابل للتعديل بحجم الأعمدة والصفوف وتنسيق النص (تجربة Excel)

- استبدال `<table>` الحالي بشبكة قابلة للتحرير مبنية على **TanStack Table** + **react-resizable-panels**/CSS resize للأعمدة.
- كل عمود: قابل لتغيير العرض بالسحب (drag handle على الحدود)، ويُحفظ العرض في `localStorage` لكل مشروع.
- كل صف: ارتفاع قابل للتعديل (drag على الحد السفلي للصف الأول من البند).
- كل خلية وصف/رقم بند: قابلة للتحرير المباشر (inline edit) — نقرة مزدوجة تفتح Input.
- شريط تنسيق بسيط فوق الجدول (Bold / Italic / محاذاة يمين-وسط-يسار / حجم خط) يطبّق على الخلية أو الصف المحدد. يُحفظ التنسيق في حقل JSON `cell_styles` على الصف.

## 3) إزالة أعمدة التكلفة من جدول الكميات

تُحذف من الواجهة الأعمدة:
- مواد، عمالة، معدات، مقاول باطن.

تبقى الأعمدة: رقم البند، الوصف، الوحدة، الكمية، **سعر الوحدة**، الإجمالي، إجراءات (+ الأعمدة الإضافية المستوردة من Excel إن وجدت).

تكاليف المواد/العمالة/المعدات/مقاول الباطن تظل تُعرض وتُحرَّر فقط داخل صفحة **تحليل الأسعار** (كما هي حالياً عبر `price_analysis_items` مقسّمة على `material/labor/equipment`). نضيف قسماً رابعاً `subcontractor` في تحليل الأسعار + تحديث enum.

**سعر الوحدة في جدول الكميات** يُحسب من تحليل الأسعار:
- مجموع `quantity × unit_price` لكل عناصر `price_analysis_items` للبند + الهوامش من `price_analysis_markup`.
- إن لم يوجد تحليل أسعار للبند → يُعرض سعر الوحدة المخزّن مباشرة على `boq_items.unit_price` (عمود موجود).

## 4) النقر على "سعر الوحدة" يفتح تحليل الأسعار للبند

- خلية "سعر الوحدة" تصبح زر/رابط:
  `<Link to="/price-analysis" search={{ item: node.id }}>`
- يتم إزالة أيقونة TrendingUp المنفصلة من عمود الإجراءات (أصبحت زائدة).
- صفحة تحليل الأسعار تقرأ بالفعل `?item=...` وتحدد البند تلقائياً — لا تغيير مطلوب هناك.

## القسم التقني (للمراجعة)

### Migrations
```sql
ALTER TABLE public.boq_items
  ADD COLUMN IF NOT EXISTS raw_row jsonb,
  ADD COLUMN IF NOT EXISTS cell_styles jsonb;

ALTER TABLE public.projects
  ADD COLUMN IF NOT EXISTS excel_headers jsonb;

-- توسيع enum لإضافة subcontractor
ALTER TYPE resource_type ADD VALUE IF NOT EXISTS 'subcontractor';
```

### ملفات سيتم تعديلها
- `src/components/boq/import-excel-dialog.tsx` — حفظ ترتيب الصفوف الأصلي، تخزين `raw_row` و `excel_headers`، عدم فرض هرمية إن لم يطلبها المستخدم.
- `src/routes/_authenticated/boq.tsx` — استبدال الجدول بشبكة TanStack Table مع أعمدة قابلة للتغيير + إزالة أعمدة التكلفة + جعل "سعر الوحدة" رابطاً.
- `src/components/boq/editable-grid.tsx` — مكوّن جديد للشبكة القابلة للتحرير.
- `src/components/boq/cell-format-toolbar.tsx` — شريط تنسيق صغير.
- `src/routes/_authenticated/price-analysis.tsx` — إضافة قسم "مقاول الباطن" بنفس نمط الأقسام الثلاثة.
- `src/lib/format.ts` — مساعد `applyCellStyle` لقراءة `cell_styles`.

### ملاحظات
- لا تغييرات على RLS؛ الحقول الجديدة `jsonb` nullable.
- حساب سعر الوحدة من تحليل الأسعار يتم على العميل (Query موجود بالفعل) — يُضاف Query مجمّع لكل بنود المشروع لتقليل الطلبات.
